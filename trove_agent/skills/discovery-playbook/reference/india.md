# India: official tracing routes (verify current availability)
- Bank deposits: RBI UDGAM portal (udgam.rbi.org.in) searches unclaimed deposits across participating banks.
- Income-tax e-filing portal: register as legal heir; AIS / Form 26AS show interest-paying banks, dividends and securities transactions.
- Mutual funds: MF Central, CAMS or KFintech consolidated account statement by PAN.
- Demat holdings: NSDL / CDSL consolidated account statement.
- Unclaimed dividends and shares transferred by companies: IEPF (iepf.gov.in).
- Insurance: each insurer publishes an unclaimed-amount search (policy no. or name + DOB + PAN); LIC on licindia.in.
- Provident fund: EPFO via UAN with the employer. NPS: the CRA, using the PRAN.
- Property: state land-records portal or sub-registrar; municipal property-tax records.
