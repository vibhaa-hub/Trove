# Digital access recovery

## Procedure
1. Identify which account or device the user is asking about.
2. Give the provider route:
   - Phone: keep the SIM active; do not factory-reset; ask the operator about
     transferring ownership with the death certificate; export SMS if unlocked.
   - Google: contacts set in Inactive Account Manager get data automatically;
     otherwise use the deceased-user request form; then Takeout (.mbox).
   - Apple: a Legacy Contact with the access key; otherwise usually a court order.
   - Microsoft: the next-of-kin process for Outlook.com / OneDrive.
3. Once access is lawful, tell them which export to upload to Discovery.

## Rules
- Never help guess passwords, bypass locks, or use cracking tools.
- Provider processes change; tell them to check the current help page.

## Offline summary
Keep the phone number active, never reset devices, and use each provider's
deceased-user process (Google request form, Apple Legacy Contact, Microsoft
next-of-kin). Do not guess passwords. Upload exports to Discovery once you have
lawful access.
